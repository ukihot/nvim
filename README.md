## 基本操作

### カーソル移動

| キー | 説明 |
|------|------|
| `h` | 左に移動 |
| `j` | 下に移動 |
| `k` | 上に移動 |
| `l` | 右に移動 |
| `w` | 単語の最初に移動 |
| `e` | 単語の最後に移動 |
| `b` | 前の単語の最初に移動 |
| `gg` | ファイルの最初に移動 |
| `G` | ファイルの最後に移動 |
| `0` | 行の最初に移動 |
| `$` | 行の最後に移動 |
| `{` | 前の段落に移動 |
| `}` | 次の段落に移動 |
| `<C-f>` | ページ下へ (Forward) |
| `<C-b>` | ページ上へ (Backward) |

### テキスト編集

| キー | 説明 |
|------|------|
| `x` | カーソル下の文字を削除 |
| `dd` | 行全体を削除 |
| `d{motion}` | モーション文まで削除 (e.g., `dw`, `d$`) |
| `yy` | 行全体をコピー |
| `y{motion}` | モーション文までコピー |
| `p` | カーソルの後に貼り付け |
| `P` | カーソルの前に貼り付け |
| `u` | アンドゥ |
| `<C-r>` | リドゥ |
| `.` | 最後のコマンドを繰り返す |

### 検索・置換

| キー | 説明 |
|------|------|
| `/pattern` | パターンを検索 (下へ) |
| `?pattern` | パターンを検索 (上へ) |
| `n` | 次の検索結果に移動 |
| `N` | 前の検索結果に移動 |
| `:s/old/new` | 現在行を置換 |
| `:%s/old/new/g` | ファイル全体を置換 |

## モード切り替え

### Normal ↔ Insert モード

| キー | 説明 |
|------|------|
| `jj` | Insert → Normal ⚡ (カスタムキー) |
| `i` | カーソルの前にInsert |
| `I` | 行の最初にInsert |
| `a` | カーソルの後にInsert |
| `A` | 行の最後にInsert |
| `o` | 下に新しい行を作成してInsert |
| `O` | 上に新しい行を作成してInsert |
| `<Esc>` | Insert → Normal (標準) |

### Normal ↔ Visual モード

| キー | 説明 |
|------|------|
| `jj` | Visual → Normal ⚡ (カスタムキー) |
| `v` | 文字単位で選択 |
| `V` | 行単位で選択 |
| `<C-v>` | ブロック選択 |

### Terminal モード

| キー | 説明 |
|------|------|
| `jj` | Terminal → Normal ⚡ (カスタムキー) |
| `<leader>t` | ターミナルをトグル |

## プラグイン別操作

|------|------|
| `-` | 親ディレクトリを開く |

| `<leader>E` | フローティングエクスプローラーを開く |

| キー | 説明 |

| `<C-h>` | 下に分割して開く (Horizontal split) |
| `<C-p>` | プレビューを表示 |
| `<C-c>` | Oil を閉じる |
| `<C-l>` | リフレッシュ |
| `-` | 親ディレクトリに移動 |
| `_` | カレントディレクトリを開く |
| `` ` `` | ディレクトリを変更 |

### 📝 補完 (Blink.cmp)

| キー | 説明 |
|------|------|
| `<Tab>` / `<S-Tab>` | 補完候補を移動 |
| `<Enter>` | 補完を確定 |
| `<C-space>` | 補完メニューを表示 |
| `<C-e>` | 補完を中止 |

**ドキュメント表示:**
- 補完候補上で200ms待つと自動的にドキュメントが表示されます

### 🔧 Trouble - 診断・シンボル表示

| キー | 説明 |
|------|------|
| `<leader>xx` | 診断パネルをトグル |
| `<leader>xX` | 現在バッファのみ診断をトグル |
| `<leader>cs` | シンボルをトグル |
| `<leader>cl` | LSP定義・参照をトグル |
| `<leader>xL` | ロケーションリストをトグル |
| `<leader>xQ` | クイックフィックスをトグル |

### 🔔 Noice - UI改善

**コマンドラインUI:**
- `:` で起動するコマンドモードがフローティングウィンドウで表示されます
- `?` と `/` は従来通り下部に表示

**LSP ホバー:**
- LSPホバー情報（定義表示など）がフローティングウィンドウで表示されます

### ⏱️ Fidget - LSP進捗表示

- LSPが処理中の場合、右下に進捗が表示されます
- 処理完了時に自動的に消えます

### 📋 Which Key - キーマップ表示

`<leader>` キーを押して300ms待つと、利用可能なキーマップが表示されます

### 🌈 Catppuccin - カラースキーム

- カラースキーム: `mocha` (暗色)
- 自動的に起動時に適用されます

### 🎯 Indent-blankline - インデント表示

- インデントレベルをビジュアルに表示します
- 自動的に有効です

### 📊 Lualine - ステータスライン

- ファイル名、行列番号、モード、LSP状態を表示します
- 画面下部に自動的に表示されます

### 🦀 Rustaceanvim - Rust開発

- Rustファイル (`*.rs`) が開かれると自動的に有効になります
- LSP機能、ホバー、型情報表示など

## LSP機能

LSPが接続されているとき、以下のキーが使用できます：

| キー | 説明 |
|------|------|
| `gl` | 診断情報をフローティングウィンドウで表示 |
| `[d` | 前の診断に移動 |
| `]d` | 次の診断に移動 |

### 言語別LSP対応

| 言語 | LSPサーバー | 特徴 |
|------|-----------|------|
| Lua | `lua_ls` | Lua開発 |
| Haskell | `hls` | Formatterは`ormolu` |
| TypeScript/Typst | `tinymist` | PDF自動エクスポート |
| Rust | `rust_analyzer` | Rustaceanvimで強化 |
| Python | `basedpyright` + `ruff` | 型チェック + リンター |

### フォーマッタ

ファイル保存時に自動フォーマット:

| 言語 | フォーマッタ |
|------|-----------|
| Lua | `stylua` |
| Haskell | `ormolu` |
| Rust | `rustfmt` |
| Python | `ruff_format` + `ruff_organize_imports` |

## その他

### ヤンク時のハイライト

テキストをコピー (`yy`, `y`, など) した際、コピーされた領域が150msハイライトされます。

### クリップボード統合

通常の貼り付け操作 (`p`, `P`) は常にシステムクリップボードから行われます。

### 相対行番号

- 現在行: 絶対行番号で表示
- その他: 相対行番号で表示 (j10kで10行上に移動するなど)

### カーソル行・列ハイライト

- 現在行と現在列が視覚的にハイライトされます

## 💡 Tips

1. **複数ファイルの同時編集**: `<leader>sv` で分割した後、`<leader>ff` で別ファイルを開く
2. **コマンド履歴確認**: `:` 後に `<Up>` で前のコマンドを確認
3. **キーマップ確認**: `<leader>` を押して300ms待つ
4. **フォーマット手動実行**: `:ConformInfo` でフォーマッタの状態確認
5. **LSP状態確認**: `:LspInfo` でLSPの接続状態確認

## 開発環境

### stylua による Lua コード フォーマット

stylua は Lua コードを自動的にフォーマットするツールです。

#### セットアップ

1. **stylua をインストール**

   ```bash
   # Windows (Scoop)
   scoop install stylua

   # macOS (Homebrew)
   brew install stylua

   # Linux (Cargo)
   cargo install stylua
   ```

2. **設定ファイル（`.stylua.toml`）**

   プロジェクトルートに `.stylua.toml` が配置されており、以下の設定項目が含まれています：
   - `column_width`: 1行の最大文字数（120）
   - `indent_width`: インデント幅（2スペース）
   - `quote_style`: クォートのスタイル（シングル優先）

#### 実行方法

```bash
# 全ての Lua ファイルをフォーマット
stylua lua/

# 特定のファイルをフォーマット
stylua lua/config/keymaps.lua

# ドライラン（変更内容を確認のみ）
stylua --check lua/

# 指定ディレクトリ配下の全ファイルをフォーマット
stylua .
```

#### Neovim 内での使用

conform.nvim が自動的に stylua を使用します。`:FormatWrite` で手動実行も可能です。
